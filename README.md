# 💳 Credit Card Default Prediction System

> **AI Application Lab Project**  
> **Department of Computer Science & Engineering | Chandigarh University**

An end-to-end, production-grade Artificial Intelligence and Machine Learning decision support system to predict whether a credit card holder will default on their credit card obligations in the subsequent billing cycle, enabling financial institutions to identify high-risk customers 30 days before financial loss occurs.

---

## 📌 Executive Summary

| Attribute | Details |
| :--- | :--- |
| **Problem Type** | Binary Supervised Classification (`0 = Non-Default`, `1 = Default`) |
| **Dataset** | Kaggle / UCI Machine Learning Repository — *Default of Credit Card Clients* |
| **Records & Features** | 30,000 Verified Accounts \| 24 Core Features + 6 Domain Engineered Ratios |
| **Class Distribution** | 77.88% Non-Default (23,364) vs 22.12% Default (6,636) |
| **ML Algorithms** | **Logistic Regression**, **Random Forest Classifier**, **Extreme Gradient Boosting (XGBoost)** |
| **Primary Metrics** | **ROC-AUC Score**, **Recall (Sensitivity)**, **Precision**, **Accuracy** |
| **Champion Model** | **XGBoost Classifier** (`ROC-AUC: 0.7823`, `Recall: 62.32%`) |
| **Outcome** | Early identification of risky customers for financial institutions via a 4-Tier Prescriptive Decision Engine |

---

## 🏆 Model Benchmark Comparison

All models were evaluated on an identical 20% stratified holdout test set (6,000 customer accounts: 4,673 Non-Defaults, 1,327 Defaults):

| Machine Learning Model | Accuracy | Precision (Defaulters) | Recall (Catch Rate) | F1-Score | ROC-AUC Score | Primary Operational Advantage |
| :--- | :---: | :---: | :---: | :---: | :---: | :--- |
| **Logistic Regression** (Baseline) | 74.30% | 44.10% | 60.59% | 0.5105 | 0.7515 | Highly interpretable linear coefficients |
| **Random Forest** (Ensemble) | **79.58%** | **53.86%** | 53.65% | **0.5376** | 0.7735 | Highest overall accuracy and precision |
| **XGBoost Classifier** 🏆 | 75.72% | 46.36% | **62.32%** | 0.5317 | **0.7823** | **Best discriminant power (ROC-AUC) & highest recall** |

> **Key Financial Insight:** In credit risk underwriting, **Recall** is significantly more critical than raw Accuracy. A False Negative (missing an actual defaulter) costs $5,000–$25,000+ in charge-offs and bad-debt provisions, whereas a False Positive (proactively reaching out to a reliable borrower) incurs only negligible operational friction. XGBoost detects **62.32%** of all eventual defaulters a full billing cycle ahead.

## 🛡️ 4-Tier Operational Risk Decisioning Framework

Rather than returning a raw binary label, the decision engine segments accounts into operational risk tiers with tailored institutional intervention strategies:

| Tier | P(Default) | Risk Category | Portfolio Characteristics | Recommended Financial Action |
| :---: | :---: | :--- | :--- | :--- |
| **1** | `< 20%` | 🟢 **Prime / Low Risk** | Consistently pays on time, low utilization (<30%), prime credit profile | Approve credit limit increases, preferential APRs, pre-approved premium cards |
| **2** | `20% - 45%` | 🟡 **Standard Risk** | Occasional revolving balances, manageable debt-to-limit ratio | Maintain standard credit line, routine monitoring, standard billing cycle |
| **3** | `45% - 70%` | 🟠 **Watchlist Risk** | 1-2 months delinquency, credit utilization >80%, declining payment velocity | Temporarily freeze credit limit increases, send automated SMS alerts, offer debt restructuring |
| **4** | `> 70%` | 🔴 **Critical Risk** | 2+ months severe delinquency, ballooning unpaid balances, cash-flow starvation | Immediate card freeze, block authorizations, proactive referral to recovery / collections |

## 🚀 How to Run

### Method 1: 1-Click Launch (Windows)
1. Double-click **`run.bat`**.
2. The launcher will automatically:
   - Detect Python (Python 3.10+)
   - Check and install dependencies (first time only)
   - Verify/train ML models
   - Launch the Streamlit dashboard in your default browser at `http://localhost:8501`

---

### Method 2: Manual Run (Command Line)

```bash
# 1. Navigate to project directory
cd "Credit Card Default Prediction"

# 2. Install dependencies
pip install -r requirements.txt

# 3. Train models and generate charts (optional; pre-trained models already included)
python model.py
python eda.py

# 4. Launch the web application
streamlit run app.py
```

Open your browser at: `http://localhost:8501`

## 📊 Features in Web Application

1. **🏠 Executive Overview & Live Filters:** Dataset statistics, KPI cards, interactive data filtering by default status and demographics, and data dictionary.

5. **📂 Batch Portfolio Scoring:** Score an entire portfolio of accounts simultaneously via CSV upload or a 50-account sample test.
6. **📄 Reports & Presentation Center:** 1-Click downloads of the formal **PDF Lab Report** and **PowerPoint Presentation Deck**.
